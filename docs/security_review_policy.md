# Security Review Policy

Reviewers inspect manifest declarations, dependency sources, action kinds, network behavior, local file access behavior, rollback notes, publisher identity, trust tier, and supply-chain risk.

Trust tiers are Official, Reviewed, Community, Unreviewed, Deprecated, and Blocked.

No add-on may bypass local Elysia operator approval. No add-on may become model/chat/tool-accessible without governance review. Networked add-ons must disclose outward boundary behavior.
