# Moderation Reporting

Reports are private moderation records. Public visitors may submit reports where policies allow it, but public users cannot read reports or moderation notes.

Reportable targets include posts, comments, repository showcases, media, and code snippets.

Supported reasons include spam, harassment, unsafe code, secret or private data, misinformation, copyright or license concern, malware or suspicious behavior, privacy violation, and other.

Reporting does not automatically remove content unless future urgent controls are explicitly implemented.
