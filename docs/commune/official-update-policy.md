# Official Update Policy

Official Update is the brand-authoritative Commune room for Elysia Ecobotics / EcoSyneva Commons notices. It is not a community submission room.

Supported notice types:

- Release notes
- Roadmap notes
- Governance updates
- Security notices
- Maintenance notices
- Incident or status notices
- Policy updates
- Developer Forge notices
- Marketplace notices
- Official community notices
- Migration notices
- Official statements

Only authorized administrators may create or update Official Updates. Community members cannot submit, request publication, self-assign official authority, impersonate release/security/governance notices, or use generic Commune routes to publish official notices.

Official Updates may include structured metadata: notice type, status, severity, audience, effective date, version/tag, affected systems, related room, related public URL, related migration, known limitations, user action required, pinned/important state, comment lock state, correction/retraction/archive status, and read-only official code snippets.

Official code examples are public text only. They may be copied, but they do not expose Coding Cornucopia workbench, sandbox run, proposal, install, deployment, Local Elysia, Developer Forge, or Marketplace approval controls.

Corrections, retractions, comment locks, pinning, priority changes, official code edits, and archives should record audit events in `commune_official_update_events` after `2026_06_26_official_update_structured_workflow.sql` is applied.

Official Update is separate from Elysia Iteration Showcase, Repository Showcase, Coding Cornucopia, Developer Forge, and Marketplace review. A notice can reference those systems, but it does not grant safety, compatibility, installability, marketplace readiness, or trust by itself.
