# Troubleshooting Grove Policy

Troubleshooting Grove is a distinct Commune room for bug reports, install issues, known problems, support threads, redacted logs, reproduction steps, workarounds, collaborative diagnosis, and proposed fixes. It may reuse Coding Cornucopia code tools, but it is not Coding Cornucopia and should not become a generic code-sharing room.

What the website may store and show:

- issue type, affected area, troubleshooting status, and environment/version context
- steps to reproduce or steps already tried
- expected result, actual result, error message, redacted logs, and known workaround
- body, tags, links, and moderated attachments
- optional redacted code/reproduction snippet linked through commune_code_snippets
- sandbox diagnostics for eligible snippets when the sandbox endpoint is configured
- proposed fixes through the shared author-controlled code proposal workflow
- accepted fix/workaround summary, resolution status, and public issue history

What the website must not accept or imply:

- unredacted secrets, API keys, tokens, .env files, passwords, credentials, private local paths, private account data, or machine inventories
- private local Elysia memory, files, logs, vaults, sealed memory, or credentials
- direct browser execution, Supabase/Postgres execution, Local Elysia execution, root execution, shell execution, package installation, repository clone/run, or network access
- sandbox success as safety, approval, compatibility, Marketplace readiness, or trust

Normal users submit Troubleshooting Grove posts for moderation. Administrators may direct-publish while preserving media safety and review history. Published posts create normal Commune threads for comments and replies under the existing thread participation/moderation model.

Original authors control accepted fixes and accepted workarounds for their own issue. Moderators enforce safety, hide unsafe content, and recover/moderate posts, comments, attachments, and proposals, but moderator safety enforcement is separate from replacing an author's public reproduction snippet.
