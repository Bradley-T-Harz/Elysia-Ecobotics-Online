# Realtime Chat Boundary

Realtime Commune chat is a future foundation, not an unsafe launch surface.

Before public write access is enabled, chat needs moderation, rate limits, report controls, retention policy, room roles, no private DMs by default, no file uploads, and clear private-data warnings.

Messages should be plain text. Hidden or removed messages must not be public.

Current status: realtime is a prepared foundation, not a launched public chat product. Public write access should wait for moderation queues, report handling, rate limits, retention policy, role rules, and clear no-secrets/no-private-local-Elysia warnings.
