# Future Local Elysia Integration Plan

Later, local Elysia can fetch the public approved catalog, validate manifests, compare them against local status, and present install/uninstall/enable/disable actions inside the local password-gated Add-ons room.

The website should remain a marketplace/profile/submission surface. Local Elysia remains the execution authority.

Optional future account linking should use a short-lived pairing code. Local inventory sync must be opt-in and must clearly show what leaves local control.
