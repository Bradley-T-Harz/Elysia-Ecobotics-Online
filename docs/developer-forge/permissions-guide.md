# Permissions Guide

Permissions explain what an add-on may request later inside local Elysia. Users and local Elysia can deny permissions during local review.

Low-risk permissions cover bundled theme assets and public metadata. Medium and high-risk permissions need clear reasons and reviewer attention.

Blocked permissions include `vault_access`, `credential_access`, `private_memory_access`, `silent_shell_execution`, `read_all_files`, `write_arbitrary_files`, `silent_network_access`, and `silent_install`. These are listed for clarity, not to enable them.
